# 🎬 Brilian.Ai — Demo Script Webinar
### *Live Product Walkthrough — Estimasi: 7–10 Menit*

---

> [!IMPORTANT]
> **Persiapan sebelum demo:**
> - Login sudah dilakukan, tab browser sudah terbuka di halaman utama
> - Siapkan 3 file sample: `laporan-keuangan-q3.pdf`, `data-penjualan.xlsx`, `sop-hr.pdf`
> - Zoom browser ke 125% supaya teks terlihat jelas dari belakang
> - Matikan notifikasi OS dan browser

---

## 🎬 SCENE 1 — Login & First Impression (0:00–1:00)

**Yang ditampilkan**: Halaman login → Dashboard utama

**Script**:
> *"Oke, kita mulai dari awal — ini tampilan login Brilian.Ai. Simple, clean, enterprise-ready."*

**Aksi**:
1. Ketik kredensial → Login
2. Biarkan audience melihat dashboard sebentar
3. Hover ke beberapa card yang sudah ada

**Yang ditekankan**:
> *"Ini dashboard-nya — semua insight perusahaan langsung tersaji di sini. Tapi sebelum kita explore, saya mau tunjukkan dulu cara data masuk ke sistem."*

---

## 🎬 SCENE 2 — Upload Dokumen (1:00–2:30)

**Yang ditampilkan**: Fitur ingestion / upload dokumen

**Script**:
> *"Bayangkan Anda punya laporan keuangan Q3 — 80 halaman PDF. Cukup drag & drop ke sini."*

**Aksi**:
1. Buka menu **Documents / Knowledge Base**
2. Klik **Upload** → drag file `laporan-keuangan-q3.pdf`
3. Tunjukkan progress ingestion berjalan
4. Upload `data-penjualan.xlsx` sebagai file kedua

**Yang ditekankan**:
> *"Perhatikan — file Excel ini diproses tanpa memanggil AI sama sekali. Brilian.Ai punya teknologi Zero-Token untuk data tabular. Artinya ribuan baris data bisa masuk tanpa biaya API."*

> *"Dan lihat — bisa set level akses: Internal, Confidential, atau Top Secret. Dokumen sensitif tidak akan bisa diakses oleh user yang tidak berwenang."*

---

## 🎬 SCENE 3 — AI Chat dengan Sitasi (2:30–4:30)

**Yang ditampilkan**: Fitur AI Chat / Copilot

**Script**:
> *"Nah ini bagian yang paling saya suka. Dokumen sudah masuk — sekarang kita tanya langsung."*

**Aksi**:
1. Buka **AI Copilot / Chat**
2. Ketik: *"Apa kesimpulan utama dari laporan keuangan Q3 kita?"*
3. Tunggu response → tunjukkan jawaban dengan **sitasi halaman**
4. Klik salah satu sitasi

**Yang ditekankan (sambil menunjuk layar)**:
> *"Lihat di sini — AI-nya tidak cuma jawab, tapi kasih tahu: 'jawaban ini dari halaman 23, section 4.2'. Klik → langsung loncat ke halaman itu di dokumen aslinya."*

> *"Ini yang membedakan Brilian.Ai dari ChatGPT biasa — AI kita tidak mengarang. Setiap klaim ada buktinya."*

**Follow-up question (bonus jika waktu cukup)**:
- Ketik: *"Bandingkan revenue bulan Juli vs Agustus"*
- Tunjukkan jawaban cross-document (dari PDF + Excel sekaligus)

---

## 🎬 SCENE 4 — Dashboard Analitik (4:30–6:30)

**Yang ditampilkan**: Dynamic Dashboard + Chart Morphing

**Script**:
> *"Oke, sekarang kita lihat magic-nya. Saya klik 'Buat Dashboard' dari data penjualan tadi."*

**Aksi**:
1. Navigasi ke **Dashboard**
2. Klik **+ Add Card / Widget** → pilih dari data Excel yang diupload
3. Tunjukkan card analitik muncul (tabel/chart)

**Morphing chart — ini momen WOW:**
4. Klik tombol **chart type** → ubah dari Tabel → Bar Chart
5. Klik lagi → Pie Chart
6. Klik lagi → Line Chart
7. **Drag card** ke posisi lain → **Resize** card dengan tarik sudut

**Yang ditekankan**:
> *"Satu klik — chart langsung berubah jenis. Tidak perlu export ke Excel, tidak perlu minta tolong tim IT. Siapa pun di tim bisa bikin dashboard profesional dalam 2 menit."*

> *"Dan ini bisa di-share ke stakeholder dengan link khusus — mereka bisa lihat dashboard tapi tidak bisa edit datanya."*

---

## 🎬 SCENE 5 — Floating Copilot di Dashboard (6:30–7:30)

**Yang ditampilkan**: AI Copilot Canvas di atas dashboard

**Script**:
> *"Sekarang saya ada di dashboard — dan saya mau tanya sesuatu tanpa pindah halaman."*

**Aksi**:
1. Klik icon **floating copilot** (pojok layar)
2. Panel chat muncul di atas dashboard
3. Ketik: *"Produk mana yang trendnya turun 2 bulan terakhir?"*
4. Tunjukkan AI jawab berdasarkan data yang sudah ada di dashboard

**Yang ditekankan**:
> *"AI-nya bisa baca konteks dashboard yang sedang Anda buka. Tidak perlu copy-paste data ke chat — dia sudah tahu."*

---

## 🎬 SCENE 6 — Documentation Center (7:30–8:30)

**Yang ditampilkan**: Docs + Command Palette Search (Ctrl+K)

**Script**:
> *"Terakhir — untuk tim yang butuh dokumentasi internal yang terstruktur, ada Documentation Center."*

**Aksi**:
1. Buka halaman **Docs**
2. Tekan **Ctrl+K** → Command palette muncul
3. Ketik "onboarding" → hasil langsung muncul dengan icon dan kategori
4. Klik salah satu hasil → langsung loncat ke halaman itu

**Yang ditekankan**:
> *"Search-nya bisa multi-bahasa, ada filter per kategori, navigasi pakai keyboard. Tim tidak perlu scroll panjang cari halaman yang tepat."*

---

## 🎬 CLOSING — Wrap Up (8:30–9:00)

**Script**:
> *"Itu tadi adalah Brilian.Ai dalam kurang dari 10 menit. Upload dokumen, tanya AI, dapat jawaban dengan bukti, buat dashboard, share ke tim — semua dalam satu platform, semua di server Anda sendiri."*

> *"Kalau ada yang mau coba langsung atau punya pertanyaan teknis, kita buka sesi Q&A sekarang."*

---

## ⚠️ Contingency Plan (Jika Ada Masalah)

| Masalah | Solusi |
|---|---|
| Internet lambat / upload lama | *"Biasanya ini lebih cepat, tapi sambil nunggu saya jelaskan prosesnya..."* → switch ke file yang sudah ada |
| AI response lambat | *"Model AI sedang diproses — ini normal untuk dokumen besar..."* → tunjukkan fitur lain dulu |
| Chart tidak muncul | *"Mari kita lihat dari data yang sudah ada sebelumnya..."* → navigate ke dashboard yang sudah ada |
| Browser crash | Buka tab baru → langsung login ulang (password manager sudah siap) |

---

## 🎯 Key Moments yang HARUS Maksimal

> [!TIP]
> **Momen #1 — Sitasi halaman** (Scene 3): Zoom in ke sitasi sebelum klik. Buat audience anticipate dulu.

> [!TIP]
> **Momen #2 — Chart morphing** (Scene 4): Lakukan perlahan, sambil komentar *"Tabel... Bar... Pie... semua satu klik."*

> [!TIP]
> **Momen #3 — Ctrl+K** (Scene 6): Bilang *"Tonton ini..."* sebelum tekan shortcut — biasanya ini yang paling bikin tepuk tangan.
